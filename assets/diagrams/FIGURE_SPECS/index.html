    Figure Specs¶

    Two kinds of visuals are used in these docs:

    1. Mermaid diagrams — written as code throughout the docs. They render automatically on GitHub and on the hosted site, and are editable as text. No image generation needed. The rest of this page lists where they live.
    2. Rich conceptual visuals — polished illustrations Mermaid can't produce (hero images, layered concept art, marketing-grade figures). These are specified below as generator-ready prompts so you can produce them later with an image tool and drop the files into docs/assets/diagrams/.

    Part B — Rich visuals to generate (prompts)¶

    Each entry gives a suggested filename, where it would go, and a generator prompt. Style guidance is shared below so the set looks consistent.

    Shared style guide¶

    Modern, clean, professional SaaS aesthetic. Indigo-to-deep-purple accent palette on a light background (and a dark-mode variant where noted). Flat vector / subtle depth, generous whitespace, rounded shapes, thin consistent linework. No stock-photo people, no clutter, no fake chart numbers. Legible labels. 16:9 unless stated.

    How to add a generated image to the docs¶

    1. Generate the image from the prompt and save it into docs/assets/diagrams/ (e.g. docs/assets/diagrams/hero.png).
    2. Reference it in the relevant markdown page, for example in index.md: 
      ![AutoAgentAI concept](assets/diagrams/hero.png)
      (Paths are relative to the markdown file. From docs/index.md, use assets/diagrams/hero.png; from a page in docs/specs/, use ../assets/diagrams/hero.png.)
    3. Commit and push — the site rebuilds automatically.

    You don't have to generate anything to ship

    The Mermaid diagrams already carry every page. The Part B visuals are polish for when you want a more designed look — generate them on your own schedule.
